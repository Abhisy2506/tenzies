# Tenzies Game

A fun, fast-paced dice game built with React and Vite.

## 🎲 Core Idea & How to Play

The objective is to get all 10 dice to display the same number in as few rolls as possible:

1. **Roll** the dice to start.
2. **Click** any die to freeze (hold) it at its current value.
3. Keep rolling the unfrozen dice until all dice match.
4. When all 10 dice match and are held, you win! 🎉

---

## 🚀 Tech Stack

- **React 19**
- **Vite**
- **react-confetti** (celebration animation on win)

---

## 🛠️ Getting Started

### Prerequisites
Make sure you have Node.js installed.

### Installation & Run

1. Clone or download the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the displayed local URL (usually `http://localhost:5173`) in your browser.
